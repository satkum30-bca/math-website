Identities of Fibonacci Numbers

Watch what happens when we take the determinant of the Fibonacci-Q matrix.

det ( [ 1 1 1 0 ] n ) = (−1)n = det ( [ F n + 1 F n F n F n − 1 ] ) = F n + 1 F n − 1 − Fn2

This identity is known as Cassini's identity. A lot of other identities can be easily derived using matrices. For a challenge, try to derive a new identity from this:

Q2n = Qn Qn
