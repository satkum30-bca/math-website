Identities of Fibonacci Numbers

Go Back

Watch what happens when we take the determinant of the Fibonacci-Q matrix.

det ( [ 1 1 1 0 ] n ) = (−1)n = det ( [ F n + 1 F n F n F n − 1 ] ) = F n + 1 F n − 1 − Fn2

This identity is known as Cassini's identity. A lot of other identities can be easily derived using matrices, as can be seen in the exercises.

Fn2 − F n + k F n − k = (−1)n−k Fk2

F m F n + 1 − F m + 1 F n = (−1)n F m − n

F n + 1 2 − F n − 1 2 = F 2 n

10.

It is easy to see that the formula for geometric series holds for matrices (the proof is similar to with real numbers).
A + AB + AB2 + ⋯ + ABn−1 = A ( I − Bn ) ( I − B ) − 1
Prove:
  • ∑ i=1 n F i = F n+2 − 1
  • ∑ i=1 n F 2n−1 = F 2n
  • ∑ i=1 n F 2n = F 2n+1 − 1
  • ∑ i=1 n ( − 1 ) i + 1 F i = ( − 1 ) n + 1 F n−1 + 1
using this fact. (Hint: First think about what the "common ratio" matrix would be in each of these sums.)
