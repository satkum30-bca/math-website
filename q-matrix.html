The Fibonacci Sequence: Intro

Go Back

The Fibonacci Sequence is defined as:

F n + 1 = F n + F n − 1
F 0 = 0 ,   F 1 = 1

We can look at the Fibonacci recurrence in a different way, using the language of matrices and difference equations.

[ F n + 1 F n ] = [ 1 1 1 0 ] [ F n F n − 1 ] = [ 1 1 1 0 ] n [ 1 0 ]

This matrix looks quite interesting. Investigating further, we get

[ F n F n − 1 ] = [ 1 1 1 0 ] n − 1 [ 1 0 ] = [ 1 1 1 0 ] n − 1 ( [ 1 1 1 0 ] [ 0 1 ] ) = [ 1 1 1 0 ] n [ 0 1 ]

This is interesting. We now see that

[ 1 1 1 0 ] n = [ F n + 1 F n F n F n − 1 ]

We call the matrix [ 1 1 1 0 ] the Fibonacci-Q matrix, denoted by Q.

This matrix is awesome since it generates Fibonacci numbers for us! We have successfully turned our recursive sequence into linear algebra. From here, we can do tons of cool stuff (click the links above)!
